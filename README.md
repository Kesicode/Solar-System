# 🌌 3D Solar System

An interactive 3D Solar System built with **React**, **Three.js**, **Tailwind CSS**, and **GSAP**.

Developed & Maintained by **[Kesicode](https://github.com/Kesicode)**.

---

## ✨ Features

- **Interactive 3D Planet Exploration**: Realistic rendering of planets using Three.js with texture and bump maps.
- **Cinematic Transitions**: Smooth camera and lighting transitions powered by GSAP.
- **Interactive Controls**: Drag to rotate planets, click planets or navigate using the side selector.
- **Atmospheric Glow**: Custom vertex and fragment shader materials for atmospheric Fresnel glow effects.
- **Responsive Design**: Polished UI with Tailwind CSS and Framer Motion / Motion.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Kesicode/Solar-System.git
   cd Solar-System
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

- **Framework**: React 19 + Vite
